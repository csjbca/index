Valentines Format

HTML • CSS • JavaScript

A responsive Valentines greeting website which asks the user a question "Will you be my Valentine?" and provides two buttons for the user to choose from. If the user clicks "Yes", a heart animation will appear on the screen, while if the user clicks "No", the yes button will grow and cover the no. It was built using only HTML, CSS, and JavaScript while focusing on clean design and responsive layouts.
